# anvelli. — logo package v1 (Sept 2026)

## The mark
Wordmark only. Lowercase "anvelli" + accent period. No symbol, no alternate marks.

- Typeface: Figtree (Google Fonts)
- Weight: 500 (600 at/below 20px, 700 at/below 14px)
- Tracking: -0.035em (-35)
- Case: always lowercase. Never "Anvelli." in the mark.

## Icon
The letter "a" + the dot, on a rounded tile (radius = 23% of tile).
At 16px, drop the dot and set the "a" at 700.

## Color
Ink            #0B0C0D
Paper          #F4F3F1
Accent (dark)  #7FD1C1   — the dot on dark grounds
Accent (light) #1F8C77   — the dot on light grounds
Muted          #9BA1A6

Dark ground is primary. On any ground that is not near-black or
near-white, use the monochrome mark: the dot takes the word's color.

## Clearspace
Minimum clearspace on all four sides = the cap height of the "l".

## Minimum size
Screen: 14px tall wordmark.
Print:  11px / 8mm wide.
Below that, use the icon — never a shrunken wordmark.

## Type system
Figtree           — logo and interface, 400/500/600/700
JetBrains Mono    — labels, values, metadata; uppercase, tracking +0.18em

## Don't
- Re-track or re-space the letters
- Capitalize the A
- Put the accent color on the word instead of the dot
- Italicize, outline, shadow, gradient, or rotate the mark
- Place the mark on a busy photo without a solid plate
