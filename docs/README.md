# anveli Documentation

Reference material for the product and the website. Use it as the source of truth for messaging, positioning and design.

The brand name is **anveli.** (lowercase, one "l"). Older mentions of "Avelli" or "anvelli" are outdated.

## Product

| Doc | What it covers |
| --- | --- |
| [Problem Brief](product/01-problem-brief.md) | The ten connected problems caused by scattered health information, and the core problem: *healthcare remembers encounters, not the person.* |

| [Our Approach](product/03-our-approach.md) | The personal health continuity layer: 45 capabilities, the product experience, and the five core layers (Health Vault, Health Intelligence, Health Continuity, Healthcare Companion, Insurance Companion). |

## One-line summary

A persistent personal health layer that stays with the individual across providers, devices, insurers and time: **Remember → Structure → Understand → Monitor → Act → Communicate → Protect.**

Motto: **Your health, understood.**
